# Nirav Kanthed — Portfolio

Personal portfolio site for **Nirav Kanthed**, a Data Science student at UC San Diego working on software and machine learning engineering.

**Live site:** https://nkanthed06.github.io/Portfolio/

## What's on it

- **About:** a short bio covering my work at Amazon Prime Video, IBM (HashiCorp Vault), Lemn-Lab, and SanQuest, plus leadership at DataHacks (DS3) and ACM.
- **Experience:** all four roles with dates, highlights, and the tech used in each.
- **Projects:** TokenLens, ReviewReady, JobTrackr, CrimeWatch SD, and Power Outage Analysis, each linked to its GitHub repo.

## Built with

- A single `index.html` file of plain HTML, CSS, and a little JavaScript; there are no frameworks and no build step.
- The [Inter](https://fonts.google.com/specimen/Inter) font from Google Fonts.
- Project logos drawn as inline SVG, with images embedded in the file.

Features include a sticky side nav that tracks the current section, a cursor spotlight, hover highlighting on cards, a copy-email button, and a responsive layout for mobile.

## Run locally

```bash
git clone https://github.com/nkanthed06/Portfolio.git
cd Portfolio
open index.html   # or just double-click the file
```

## Deploy

The site is hosted with **GitHub Pages** from the `main` branch root (configured under Settings → Pages). Pushing to `main` updates the live site within a minute or two.
