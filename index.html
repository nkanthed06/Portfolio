About

I'm a Data Science student at UC San Diego who cares most about what happens after the notebook: getting a model trained reliably, tested before it ships, and explained to the people who depend on it.

Outside of work I'm President of the DataHacks team at DS3 and a Director at ACM, and I keep shipping side projects like TokenLens, ReviewReady, and JobTrackr.

Projects

  1. TokenLens ↗

    A Cursor / VS Code extension and Claude Code plugin that estimates output token usage before you send a prompt. A scikit-learn model trained on 12,052 coding prompts reaches a median absolute error of 180 tokens on Claude Haiku 4.5, and a LangGraph workflow suggests and ranks prompt rewrites from accept/reject history in MongoDB Atlas, exposed through an MCP server.

    • TypeScript
    • Python
    • scikit-learn
    • LangGraph
    • MongoDB
    • MCP

  2. ReviewReady ↗

    Paste a GitHub pull request link and get an AI code review: a plain-English summary, a 0–10 risk score, likely missing tests, and reviewer-style inline comments. The risk score blends a local heuristic with Claude's structured output, and every analysis is saved to Supabase with a shareable URL. Deployed on Cloudflare Workers.

    • React 19
    • TanStack Start
    • Tailwind
    • Supabase
    • Anthropic API
    • Cloudflare Workers

  5. Power Outage Analysis ↗

    A study of how the cause of a U.S. power outage relates to its severity, using 1,534 major outages from 2000–2016. Permutation tests showed cause and severity are not independent (p = 0.001), and a tuned Random Forest using cause, NERC region, and climate improved R² from −0.016 to 0.147 over a linear baseline, with a fairness check across regions.

    • Python
    • pandas
    • scikit-learn
    • Random Forest
    • Hypothesis Testing
